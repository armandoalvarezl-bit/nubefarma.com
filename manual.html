1 Objetivo del sistema

Farma POS es una plataforma para la operacion diaria de farmacias o puntos de venta similares. Permite:

  • Iniciar sesion con usuarios validados en linea.
  • Registrar ventas y emitir tickets.
  • Controlar inventario y sincronizar con Google Sheets.
  • Gestionar clientes y puntos.
  • Registrar retiros de caja.
  • Realizar cierres de caja.
  • Consultar historico de ventas.
El sistema funciona en interfaz web y tambien en modo escritorio con Electron.

2 Estructura general

Las principales pantallas del sistema son:

  1. pos.html: ingreso al sistema.
  2. dashboard.html: panel general.
  3. ventas.html: punto de venta.
  4. historico-ventas.html: consulta y anulacion de tickets.
  5. retiros-caja.html: retiros de caja.
  6. cierre-caja.html: cierre diario o por turno.
  7. clientes.html: registro y consulta de clientes.
  8. reporte.html: reportes de gestion.
El logo puede mostrarse en la fase y nombre, pero los datos de tu farmacia siempre van primero.

3 Requisitos de uso

Conexion a internet para validar usuarios y sincronizar informacion.

Google Sheets + Apps Script configurado.

Usar un navegador moderno como Chrome, Edge o Firefox.

Para modo escritorio:

  • Node.js 20 o superior.
  • npm install
  • npm start

4 Inicio de sesion

  1. Escribe el usuario.
  2. Escribe la contrasena.
  3. Pulsa Entrar al sistema.
Acceso protegido por usuario y contrasena.
